# 🛍️ ShopSphere - Online Shopping Website

![ShopSphere Banner](https://img.shields.io/badge/Project-E--Commerce-blue)

## 📌 Project Overview

ShopSphere is a full-stack e-commerce web application developed as part of the **CodeAlpha Full Stack Development Internship**.

The main objective of this project is to build an online shopping platform where users can browse products, search products, add items to cart, and manage their shopping experience through an interactive user interface.

The project demonstrates frontend development, backend API creation, and database integration concepts.

---

## 👤 User Features

# ⚙️ Installation and Setup

## Step 1: Clone Repository

```bash
git clone https://github.com/shaikumarfarooq2112-coder/CodeAlpha_EcommerceStore.git
```

---

## Step 2: Navigate to Project Folder

```bash
cd CodeAlpha_EcommerceStore
```

---

## Step 3: Install Backend Dependencies

Move into backend folder:

```bash
cd backend
```

Install required packages:

```bash
npm install
```

---

## Step 4: Start Backend Server

Run:

```bash
node server.js
```

The server will start successfully:

```
Server is running on port 3000
```

---

## Step 5: Run Frontend

Open:

```
frontend/index.html
```

Run the frontend using **Live Server** in Visual Studio Code.

# 🚀 Application Workflow

1. User opens the ShopSphere website.
2. User views available products.
3. User registers a new account.
4. User logs into the application.
5. User selects products.
6. Products are added to the shopping cart.
7. User reviews cart items.
8. User proceeds towards checkout.
